Rules this frame holds to

  • Nothing moves unless something real happened: a message, a worker ready, a lock won. The board has no render loop.
  • No gradients, no blur, no grain. The glow is four hard steps, and a dither in Ink.
  • Square corners, strong ink borders, hard offset shadows, stencil labels.
  • One vermilion, only for live states. Never lime, never purple.
  • Every drawing is vector, built in code, with a seeded pen wobble. No generated imagery, no photographs.
  • A lamp is a button, the board has a spoken description, and every state has a word as well as a colour.

Provenance: the geometry is drawn by the same code the site ships, src/sections/control-room/board-art.ts, board-cables.ts and lamp-positions.ts; the words come from src/data/copy.ts; the titles and headline metrics from src/data/portfolio.ts; the tokens and the five latin font files from the repository. The page has no scripts.
